CAUSE (voice language)
  The turn-37 hook assumed sub_82481E78(id). Disassembly:
    82481E78(r3 = UTF-16 name pointer): r4 = 82481CD0(Registry, name, 0)
    (name -> id via 82481C58, mapped/validated against the voice list at
    Registry+288), fallback 82481BE8; then 8230BAC0 copies the resulting name
    to the voice cache 0x83318000. 82481F40 reads that cache back to an id.
  Registry 0x8336A5F0: entries {u16 id; u16 name[6]} stride 14 at +0, count
  at +416. Callers: 82481EE8 (first use, default name 0x83238A28) and config
  apply 82870E38 via 82482038(voice index) = 82481BE8(Registry, list[index]),
  i.e. a registry name pointer.
  The hook replaced the pointer with the integer 2, so the lookup read guest
  address 2 and fell back to the default (English).
