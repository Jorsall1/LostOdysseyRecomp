CHANGES
  * gpu/dynamic_resolution.h: stepping down jumps straight to the height whose
    pixels fit the budget (height * sqrt(budget * 0.8 / busy), rounded down to
    a rung, at least one rung) instead of one or two rungs a second. 1080 rows
    at 29 ms -> 720 in one rebuild instead of nine.
  * settings/config.h, graphics_menu.h, menu.cpp (Switch 2 only):
    - Automatic scene height 720 rows handheld, 1080 docked (was 1080/1440).
    - Default dynamicResolution false, minimum 0; every preset is a fixed
      height (Quality / Balanced / Performance differ in effects only).
      Dynamic resolution stays a menu row. Preset help text updated.
    - A saved settings.ini keeps its own values; env.txt LO_DYNAMIC_RESOLUTION=0
      overrides it.
  * movie/movie_hooks.cpp: before a native movie's first host frame, the
    player's Y/U/V textures are set once to black (Y 0, U/V 128) and reported
    as a new picture. Zeroed planes decode to green: the likely green flash
    between the loading screen and the movie.
  * gpu/renderer.cpp: LO_TEXTURE_NO_MIPS=1 loads the base level only (A/B for
    a broken mip upload: 3D surfaces sample lower mips, the HUD level 0).
