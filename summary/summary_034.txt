ROOT CAUSE (black silhouettes)
  docs/archive/notes/physical-alias-rendering.md (2026-09-04) is this exact
  bug on PC: D3D GetData (sub_823CF3F0) converts a query record to physical
  and reads it at 0xC0000000 + physical (cached view), while the GPU writes
  0xA0000000 + physical. On Switch 2's heap backend C is separate zeroed
  memory, so every END record read 0, not the sentinel: "ready", 0 pixels.
  UE3 (sub_823CE960) then clears the primitive's visibility bit and the base
  pass (sub_823D0500) skips it: skeletal meshes keep only depth/shadow passes.
  Exactly 13 sites in 11 functions do physical -> 0xC0000000 (`addis
  rX,rY,-16384` after the inlined MmGetPhysicalAddress): 823CDCA8 x2,
  823CE2C0, 823CF3F0 x2 (types 9 and 10), 823F0D18, 8270EA78, 827B67E0,
  827B8378, 827B8F48, 827B9010, 827C08A8, 827C1648.
