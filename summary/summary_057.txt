CHANGES
  1. plume (plume-switch-perf.patch regenerated, chain reproduces the tree):
     RenderQueryPool::queryResultsFirst(count) (default: queryResults());
     VulkanQueryPool reads only the first `count` occlusion queries into a
     buffer kept between reads. renderer CompleteOcclusionQueries passes the
     slot's used count. Expect readback_ms to grow much slower.
  2. gpu/op_ring.h: Record() no longer locks a mutex for every draw (~2100 a
     frame); single writer (renderer thread), `next` is atomic, the GPU-stop
     dump takes a snapshot of it.
  3. CPU profiler (os/switch/cpu_profiler_switch.cpp): samples inside
     mutexLock, mutexUnlock, pthread_mutex_lock/unlock, memcpy/memmove,
     memset and memcmp also record the sampled line, LR and 4 stack return
     addresses. stderr gets "helpers in N samples" blocks per thread;
     tools/switch/switch-cpu-profile.py prints them as
     "in shared helpers ... from: mutexLock <- pthread_mutex_lock <- X <- Y"
     (--helpers N lines). Old logs parse the same as before.
