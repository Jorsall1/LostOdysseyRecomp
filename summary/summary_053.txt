CHANGES
  1. Early depth tests (LO_EARLY_Z, default on, Switch 2). Every translated pixel
     shader holds the alpha test's discard, so NVK tested depth after shading on
     every draw (hidden pixels shaded). Switch 1's deko3d equivalent: GPU 53 ->
     41.5 ms, +20% FPS.
     * plume (patch regenerated): VulkanShader makes an EarlyFragmentTests twin
       of each fragment module (spirv_trim::AddEarlyFragmentTests);
       RenderGraphicsPipelineDesc::earlyFragmentTests picks it (non-library
       path; the fast-link library path stays late-Z).
     * renderer: CheckShaderDiscard now runs on Switch 2 (mayDiscard = clip() /
       depth write / translation errors). Texinfo-specialised variants carry an
       "early" flag (SpecVariant::early, desc.earlyFragmentTests); a draw asks for
       early when ps && !mayDiscard && alpha test off; seeds from recipes are
       early when the shader cannot discard. Generic (late-Z) pipeline is bound
       until the variant is built in the background. FinishSpecialisation matches
       by job pointer.
  2. Lean SPIR-V (LO_LEAN_SPIRV, default on, Switch 2): OpDecorate NoContraction
     removed at module creation (HLSL precise on SV_Position and its inputs),
     letting the compiler fuse mul+add. Switch 1 lean level 2: hot vertex shaders
     -30-34% code, GPU ~-10%. stderr "[lean] N shaders without NoContraction".
     Risk: position rounding between passes (z-fighting in depth-equal passes);
     Switch 1 shipped with it.
  3. Restore skip and blit resolve on again on Switch 2 (LO_SKIP_RESTORE=0 /
     LO_RESOLVE_BLIT=0 off): cleared as GPU-stop suspects (stops in turns 48,
     50, 51 happened with them off). Switch 1: ~2 ms GPU per battle frame.
  4. dynamic_resolution UpBelow 0.80 -> 0.85: steps up when the next rung is
     predicted under 14.2 ms (was 13.3) at 60 FPS.
