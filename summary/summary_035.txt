CHANGES
  GPU time (gpu/gpu_busy.h)
    * AddBatch counts the union of batch intervals: overlap between the two
      in-flight GPU slots was counted twice (gpu_pct 158). gpu_ms/gpu_pct now
      mean real busy time, and dynamic resolution reads the real cost.
    * Longest single batch per perf window: new perf field gpu_batch_max_ms.
  Dynamic resolution (Switch 2)
    * Back on by default. Max = native (1080 rows handheld, 1440 docked: no
      upscale there, FSR is skipped at scale 1); floor 576 handheld, 1152
      docked (settings::SwitchAutomaticMinimum, used when Minimum is Auto).
      1152 added to SwitchSceneHeights. Budget 16.7 ms (60 FPS).
    * Removed the Switch 2 hard-off in gpu/frame_plan.cpp, graphics_menu.h
      DynamicResolutionOn and the config.cpp Validate lock; every preset is
      dynamic over the Auto range (they differ in effects only); Graphics shows
      Maximum/Dynamic/Minimum resolution again with new help texts.
    * settings.ini: new key resolution_layout=2. A file without it (written
      while turn 34 forced the values) takes the new defaults once.
  Shadow targets (gpu/render_resolution.h)
    * The 880/440-pitch shadow colour family (880x896, 880x448, 440x448) keeps
      its guest size on Switch 2 instead of the scene scale (was
      880x896 -> 1320x1344 at 1080p) and so is no longer re-sized by dynamic
      resolution. LO_SHADOW_COLOR_SCALED=1 restores the old scaling.
      Not done: keeping guest-size targets across a resize (the whole target
      map is still cleared on a step; they are re-created at the same size).
  Device loss
    * gpu/submission_ring.h: the last 16 renderer batches (frame, draws,
      resolves, GS rect lists, occlusion queries, scene size, scene tag, GPU
      ms once completed) are printed as [error] lines by video::StopGpuWork,
      with the longest batch since the last perf line.
    * Batches end every 1024 draws on Switch 2 (as well as when descriptors
      run out), so no single submission runs as long. LO_SWITCH_BATCH_DRAWS=
      <n> (0 = old behaviour). Logged at startup ("batches end every ...").
      Unverified that this prevents the loss; the ring will say what ran.
    * Applet events in the runtime log: "applet: docked/handheld", focus
      changes, resume, and "applet: suspended, now running again (suspended N
      ms)" from the watchdog's poll gap (os/suspend_clock.h).
    * Not done: an explicit GPU drain on resume/dock (a dock that changes the
      base height already drains in the resize path). The new applet lines
      will show whether the 14 s dock fence wait was a suspension.
  Bugs
    * Movie stall timer and "native movie ... status" lines leave suspended
      time out (fixes the bogus 394591 ms dump after sleep).
    * Memory Monitor sleeps 30 s in 500 ms steps, so the exit ends it.
    * Negative "fence wait open 1844...ms" / "-1844... ms" values clamped.
  Pipeline workers (gpu/host_cores.h)
    * With process core mask 0x38 available (log said 0x3f), the long-lived
      pipeline pool sizes from 6 threads (3 workers, 2 for draw-time jobs) and
      the workers and the library thread are moved to cores 3-5. Logged:
      "renderer: pipeline worker threads on cores 3-5: yes/refused". Short
      synchronous-load pools keep 3.
  Title (settings/title_policy.h, title_entry.cpp)
    * Y: Settings footer and the Y shortcut back on Switch 2. No Back quit
      dialog and no quit legend (HOME -> X only). Prep bar and achievement
      toast stay off.
  Debug audit (quiet by default; all still available)
    * "pipeline workers frame=N" per-frame lines only when a pipeline was
      queued/built/skipped; hits/shader loads summed every 10 s
      (LO_PIPELINE_MISS_LOG=1: every frame as before).
    * Watchdog 15 s / 40 s guest dumps off (LO_GUEST_DUMPS=1).
    * Stutter samples off (LO_STUTTER_SAMPLES=1).
    * "watch:" lines are notices (queued writer), not synchronous warnings.
    * Fence-wait host backtrace off (LO_FENCE_BACKTRACE=1).
    * Kept: perf lines every 10 s, hitch lines, movie-stall dump.
  GPU pass timing (gpu/pass_timing.h)
    * LO_GPU_PASS_TIMING=1: every 10 s "gpu passes (ms per frame ...):
      scene= shadow= gs_rect= resolve= total= draw_splits=". Approximate
      (bottom-of-pipe timestamps at category changes). Off = no cost.
